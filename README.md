# Stock News

Read news about your stock portfolio.

## Features

1. Manage stock portfolio: follow/unfollow news from one stock
1. Read the summary of latest news for a stock.

## Run this App

1. Setup your OpenAI API key by environment variable "OPENAI_API_KEY"
1. (optional) Setup your model by environment variable "OPENAI_MODEL", the default model is
   "gpt-5.6-luna"
1. Install dependencies: `pnpm install`
1. Run this app: `pnpm dev --open`
